## Ключевые термины, которые полезно объяснить. 
- **Администратор** - зарегистрированный пользователь, который управляет учетными записями, настраивает рекомендации, обрабатывает жалобы и возвраты.
- **Алгоритм рекомендаций** - правила, по которым система формирует рекомендации.
- **Аналитика заказов** - количественные данные о заказах продавца: какие товары и категории заказывают, объёмы и частота; используется для анализа спроса.
- **Аналитика продаж** - финансовый отчёт продавца о выручке и прибыли по проданным товарам.
- **Возврат** - процесс приёма товара обратно продавцом и возврата покупателю денежных средств по одобренной заявке.
- **Восстановление данных** - возврат данных из резервной копии (бэкап).
- **Единица товара** - конкретный вариант товара с уникальным идентификатором (SKU)
- **Жалоба** - обращение пользователя с претензией к продавцу.
- **Заказ** - оформленная покупка конкретной единицы товара с фиксацией цены, данных покупателя и статуса выполнения.
- **Заявка на возврат** - обращение пользователя с целью вернуть товар и получить возврат денежных средств.
- **Избранное** - список товаров, которые клиент отметил для отслеживания, сохранения или потенциальной покупки в будущем.
- **ИИ-модератор** - автоматический модуль системы, самостоятельно обрабатывающий типовые жалобы пользователей.
- **История заказов** - список ранее оформленных заказов покупателя.
- **Карточка товара** - страница с полной информацией о товаре с описанием, ценой и отзывами.
- **Каталог товаров** - это список всех товаров магазина с их описаниями, ценами и изображениями, по которому покупатель ищет и выбирает товары.
- **Категория товара** - общий признак группы товаров, используемый для фильтрации.
- **Корзина** - список товаров, выбранных покупателем для покупки.
- **Обработка жалоб и возвратов** - рассмотрение обращений администратором и принятие решения, включая возврат денег.
- **Оплата** - процесс перечисления денежных средств покупателем за заказ.
- **Отзыв** - мнение покупателя о товаре, включает в себя текст, изображение и оценку.
- **Оценка** - целое число от 1 до 5, выставленное покупателем товару.
- **Параметры рекомендаций** - настраиваемые администратором значения, влияющие на работу алгоритма рекомендаций.
- **Персональные данные** - сведения, относящиеся к пользователю (имя, контакты, адрес доставки), обрабатываемые в соответствии с законодательством.
- **Поиск товаров** - функция нахождения товаров по ключевым словам.
- **Покупатель** - зарегистрированный пользователь, который ищет и выбирает товары, оформляет заказы, оставляет отзывы на товары, оставляет заявку на возврат и имеет возможность пожаловаться на продавца.
- **Продавец** - зарегистрированный пользователь, представитель бренда, который добавляет и редактирует товары, управляет заказами и анализирует продажи.
- **Резервное копирование** - создание копий данных (бэкап) для восстановления.
- **Рейтинг товара** - среднее арифметическое всех оценок, данных пользователем товару.
- **Рекомендации товаров** - подбор товаров на основе истории заказов покупателя.
- **Роль пользователя** - категория пользователя, определяющая набор доступных функций в системе.
- **Системный администратор** - зарегистрированный пользователь, который обеспечивает работу и безопасность системы, выполняет резервное копирование и восстановление данных.
- **Статус заказа** - текущее состояние заказа ("Оформлен", "Собирается" и т.д).
- **Товар** - описание позиции каталога с названием, описанием, ценой, изображениями и характеристиками.
- **Уведомления** - сообщения пользователю об изменениях, например о смене статуса заказа.
- **Управление заказами** - изменение статусов заказов продавцом.
- **Учетная запись** - совокупность данных пользователя и назначенной ему роли в системе.
- **Фильтр поиска** - набор параметров (цена, категория, характеристики), ограничивающих результаты поиска.
- **Характеристика товара** - атрибуты товара (размер, цвет и т.п.), по которым возможна фильтрация.
- **SKU (Stock Keeping Unit)** - уникальный идентификатор единицы товара, используемый для учёта.
